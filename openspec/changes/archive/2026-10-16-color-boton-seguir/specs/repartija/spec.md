## ADDED Requirements

### Requirement: Distinct roster step continue action
On the roster step, the "Seguir" control MUST use a visual style distinct from the "Agregar" control (specifically the theme's purple secondary fill rather than the gold primary fill) so advancing to subgroups does not blend with adding participants.

#### Scenario: Seguir differs visually from Agregar
- **WHEN** the user views the roster step
- **THEN** "Agregar" uses the primary gold style and "Seguir" uses the secondary purple style
